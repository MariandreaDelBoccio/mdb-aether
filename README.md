# AETHER

Lab 3D interactivo — hub + 5 demos (Liquid Metal, Living Planet, Exploded Object, Particle Universe, Organic Matter).

```bash
npm install
npm run dev
```

Abre [http://127.0.0.1:5184](http://127.0.0.1:5184).

## Scripts

| Script | Qué hace |
| --- | --- |
| `npm run dev` | Vite en el puerto 5184 |
| `npm run build` | Typecheck + build |
| `npm run preview` | Preview del build |
| `npm run deploy` | Build + `gh-pages` → `/mdb-aether/` |

## Stack

React 19 · TypeScript · Vite · React Three Fiber · drei · react-router · EN/ES

Ver `BRIEF.md` para el caso de estudio.
